# 0scan

Mobile Code Security Scanner / 手机端代码安检

I'm a self-taught developer with no formal background, and currently, I only have a mobile phone. To find hardcoded passwords in GitHub repositories, I wrote this tool using Termux. It can clone a project, scan for passwords and API keys, filter out junk files, and generate an HTML report. It's still very basic, but I will keep iterating.

我是个野路子，现在只有手机，为了找出 GitHub 里的密码，用 Termux 写了个这个。它能把项目下载下来，搜出密码和密钥，过滤掉垃圾文档，最后生成网页报告。目前还很简陋，会持续迭代。
